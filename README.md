# 💄 GB MakeUp

Projeto desenvolvido em 2024 com o objetivo de aperfeiçoar minhas habilidades em desenvolvimento Front-End, simulando um e-commerce de maquiagens moderno, responsivo e visualmente atrativo.

---

## ✨ Sobre o projeto

O **GB MakeUp** é uma simulação de uma loja virtual de maquiagens, criada para praticar conceitos de desenvolvimento web, organização de layouts e experiência do usuário.

O projeto foi desenvolvido focando em:
- Estruturação semântica com HTML
- Estilização moderna e responsiva com CSS
- Interatividade utilizando JavaScript
- Organização visual inspirada em lojas virtuais reais

---

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

---

## 🎯 Funcionalidades

- Página inicial estilizada
- Catálogo de produtos
- Cards de produtos
- Layout responsivo
- Navegação intuitiva
- Interface moderna
- Simulação visual de um e-commerce

---

## 📚 Objetivo

Esse projeto foi criado com fins de estudo e prática, buscando aprimorar minhas técnicas de Front-End e fortalecer meus conhecimentos em desenvolvimento web.

---

## 💡 Aprendizados

Durante o desenvolvimento deste projeto, pratiquei:
- Responsividade
- Estruturação de páginas web
- Organização de componentes visuais
- Manipulação básica com JavaScript
- Criação de interfaces inspiradas em e-commerces reais
